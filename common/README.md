# common

Библиотека для MVC-сервисов: JWT Resource Server, BCrypt, методная безопасность, единый ErrorDto/Errors, traceId и общие демонстрационные идентификаторы. Самостоятельно не запускается; собственной БД нет. Не зависит от бизнес-сервисов. OpenAPI задаёт Bearer security scheme. Gateway использует отдельную реактивную конфигурацию.

Команды сборки и запуска я описал в [корневом README](../README.md). Полный API — в Swagger бизнес-сервисов и таблицах корневого README.
