# eureka-server

Порт 8761, панель http://localhost:8761. Spring Cloud Netflix Eureka Server. Сервисы регистрируются под именами hotel-service, booking-service, api-gateway. Реестр не регистрирует себя и не запрашивает соседний реестр. Предметных данных и БД нет.

Запускается первым. Регистрация/кэш discovery обновляются не мгновенно: после старта приложений ожидаю до 90 секунд и проверяю запрос через Gateway по инструкции в README. Адрес клиентов меняется переменной EUREKA_URL.

Команды сборки и запуска я описал в [корневом README](../README.md). Полный API — в Swagger бизнес-сервисов и таблицах корневого README.
